## How to Run

- gt_output ဖိုလ်ဒါထဲဝင်ပါ။
- Terminal မှာ `python -m http.server 8080` ဆိုတဲ့ command ရိုက်ထည့်ပါ။
- ပြီးရင် browser တစ်ခုခုမှာ http://localhost:8080/ လင့်ကနေ access လုပ်ကပါ။
- ဘာပြဿနာမှ မရှိခဲ့ရင် browser ကနေလည်း GT output တွေကို တစ်ဖိုင်ချင်း ကလစ်လုပ်ပြီး နားထောင်ကြည့်လို့ ရပါတယ်။  

အောက်ပါလိုမျိုး screen ကို မြင်ရပါလိမ့်မယ်။
