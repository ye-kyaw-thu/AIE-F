## ASR

1. ဂျပန်အစိုးရသုတေသနဌာန NICT ကျိုတိုရုံးရဲ့ VoiceTra Project မှာ လုပ်ခဲ့တဲ့ speech corpus building နဲ့ HMM based ASR pipeline ကို မိတ်ဆက်ပေးခဲ့တယ်။ [[paper]](https://www.isca-archive.org/interspeech_2015/thu15_interspeech.pdf)  
2. လက်တွေ့အနေနဲ့က [SLR80 Burmese dataset](https://www.openslr.org/80/) ကို သုံးပြီးတော့ ASR experiment တစ်ခုကိုလုပ်ပြခဲ့ပါတယ်။  
 
## TTS

1. ဂျပန်အစိုးရသုတေတနဌာန NICT ကျိုတိုရုံးရဲ့ VoiceTra Project မှာ လုပ်ခဲ့တဲ့ HMM based TTS pipeline ကို မိတ်ဆက်ပေးခဲ့တယ်။ [[paper]](https://www.isca-archive.org/interspeech_2015/thu15_interspeech.pdf)
2. လက်တွေ့အနေနဲ့က [SLR80 Burmese dataset](https://www.openslr.org/80/) ကို သုံးပြီးတော့ TransformerTTS + Guided Attention ကို အခြေခံတဲ့ TTS experiment တစ်ခုကို လုပ်ပြခဲ့ပါတယ်။
